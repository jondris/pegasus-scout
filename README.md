# 🦅 PEGASUS SCOUT
### Sistem Informasi Pramuka Penggalang SMP

Website dashboard untuk mengelola data Pramuka Penggalang tingkat SMP.

## ✨ Fitur
- 🏠 Dashboard statistik
- 👤 Data Penggalang
- ⚜️ Data Regu
- 👨‍🏫 Data Pembina
- 📅 Kegiatan
- ✅ Absensi
- 📜 SKU
- 🏆 Prestasi
- 📷 Dokumentasi
- 📊 Laporan
- ⚙️ Pengaturan

## 🚀 Deploy ke GitHub Pages

1. Buat repository baru di GitHub, misal: `pegasus-scout`
2. Upload semua file (`index.html`, folder `css/`, `js/`, `README.md`)
3. Masuk ke **Settings → Pages**
4. Pada **Source**, pilih `Deploy from a branch`
5. Pilih branch `main` dan folder `/ (root)`
6. Klik **Save**
7. Tunggu 1-2 menit, website akan live di:
   `https://username.github.io/pegasus-scout/`
